Percakapan AI Anda tersebar di situs yang berbeda. Anda terus mengetik ulang prompt yang sama, dan obrolan terbaik Anda menghilang dalam riwayat tak berujung. Folder AI adalah kokpit browser terpadu yang Anda butuhkan untuk mendapatkan kembali kendali atas ruang kerja Anda.

Atur percakapan dari semua alat AI favorit Anda dalam folder bersama, bangun perpustakaan prompt yang dapat digunakan kembali, dan suntikkan templat langsung ke kolom input mana pun — tanpa perlu menyalin dan menempel.

🌐 19 LAYANAN AI YANG DIDUKUNG

Folder AI terintegrasi secara native dengan semua asisten obrolan AI utama, seperti Claude, ChatGPT, dan Gemini, serta LLM lokal yang Anda jalankan sendiri. Percakapan dari platform yang berbeda dapat berbagi folder yang sama persis. Setiap obrolan menampilkan warna dan logo layanannya, jadi Anda selalu tahu dari mana asalnya.

🌟 MODE FOLDER

⌨️ Pintasan panel instan: Buka panel secara instan dari tab mana pun dengan Ctrl+Shift+1 (atau Cmd+Shift+1 di Mac).
⚡ Simpan Cepat (Klik Kanan & Pintasan): Simpan percakapan saat ini dengan klik kanan sederhana, atau gunakan pintasan keyboard (Ctrl+Shift+S atau Cmd+Shift+S di Mac) untuk langsung mengirimkannya ke "⚡ Simpanan Cepat" — dengan peringatan visual jika sudah tersimpan!
☑️ Pilihan Ganda (Tindakan Massal): Pilih beberapa percakapan menggunakan kotak centang untuk memindahkan atau menghapusnya dalam satu klik.
📑 Integrasi Grup Tab: Buka seluruh folder dalam satu klik sebagai Grup Tab Chrome asli dengan kode warna.
😃 Emoji Folder Khusus: Mulai nama folder dengan emoji (mis. "💻 Kode") untuk mengganti ikon folder default.
🖱️ Seret & Lepas: Susun ulang ruang kerja Anda dengan menyeret percakapan antar folder.
🗂️ Subfolder: Seret satu folder ke folder lain untuk menempatkannya di dalamnya. Buka folder induk sebagai grup tab dan semua isinya ikut terbuka.
📱 Sinkronisasi Mobile: Sakelar menghasilkan folder cermin di bookmark Chrome Anda, mereproduksi struktur folder dan urutan pengurutan kustom Anda di ponsel dengan sempurna.
🗜️ Kompresi Ultra-Efisien: Otomatis mengompresi data Anda (LZString) untuk memaksimalkan penyimpanan asli Chrome dan menyimpan ratusan percakapan.
📊 Pelacak Penyimpanan: Bilah kemajuan visual yang elegan menampilkan penyimpanan cloud yang tersedia secara real time.
📁 Folder & Pin Kustom: Susun percakapan berdasarkan proyek, tema, atau kategori. Sematkan (📌) folder favorit Anda di bagian atas.
⇅ Pengurutan Kustom: Urutkan folder dan percakapan secara langsung (Terbaru, Terlama, A-Z) dengan perubahan yang langsung tercermin dalam sinkronisasi mobile Anda.
🤖 Deteksi Cerdas & Pencarian: Pengisian otomatis judul percakapan yang tepat dan bilah pencarian real time.
☁️ Sinkronisasi Cloud & Cadangan: Akses organisasi Anda di semua perangkat dan ekspor data sebagai JSON.
🎨 Desain Material 3 & Multibahasa: Antarmuka ultra-kompak dengan dialog modal yang sepenuhnya kustom, mode gelap otomatis, dan dukungan 43 bahasa!


🏠 DUKUNGAN LLM LOKAL

Menjalankan model AI lokal (Ollama, LM Studio, Jan, atau lainnya)? Konfigurasikan Folder AI dengan URL lokal Anda — mendukung localhost dan alamat LAN (192.168.x.x, nama host khusus). Simpan cepat dan simpan melalui menu konteks juga berfungsi pada UI lokal.
✨ MODE PROMPT

📝 Perpustakaan Prompt Pribadi: Beralih ke Mode Prompt dengan satu klik pada tombol sakelar di header. Simpan prompt terbaik Anda dengan judul dan teks lengkap, lalu temukan seketika dengan pencarian dan pengurutan (terbaru, terlama, A-Z).
▶ Injeksi Satu Klik: Tidak perlu lagi salin-tempel. Klik tombol putar (▶) pada prompt mana pun untuk menyuntikkannya langsung ke kolom input AI aktif.
✏️ Pengeditan di Tempat: Klik prompt untuk meluaskannya dan edit teks langsung. Perubahan otomatis tersimpan setelah jeda singkat dan urutan pengurutan diperbarui sesuai.
🔀 Tombol Percakapan Baru: Mulai percakapan baru di salah satu layanan web yang didukung langsung dari Mode Prompt — dengan satu ketukan.
☁️ Sinkronisasi Prompt: Aktifkan sinkronisasi cloud untuk perpustakaan prompt Anda secara independen dari folder Anda.
📌 Prompt yang Disematkan: Sematkan prompt penting Anda dengan satu klik agar tetap di bagian atas perpustakaan, dipisahkan dari yang lain oleh pemisah visual.
⌨️ Pemicu Prompt dengan Saran Langsung: Ketik # di kolom chat AI mana pun untuk langsung melihat semua prompt tersimpan Anda — difilter secara real time saat Anda mengetik. Gunakan ↓/↑ untuk navigasi, tekan Spasi pada kecocokan unik untuk pelengkapan otomatis, atau pada kecocokan tepat untuk menyisipkan langsung.

🛠️ CARA KERJANYA?

Mode Folder:
Buka percakapan di salah satu platform AI yang didukung.
Buka panel: Ctrl+Shift+1 (atau Cmd+Shift+1 di Mac).
Simpan cepat: Ctrl+Shift+S (atau Cmd+Shift+S di Mac), atau klik kanan > "Simpan ke Folder AI".
Via ekstensi: Klik ikon, pilih folder, dan simpan.
Mobile: Centang 📱 di footer untuk menyinkronkan folder Anda ke ponsel.
Gunakan kotak centang untuk tindakan massal, buka folder sebagai Grup Tab (📑), seret dan lepas untuk menyusun ulang!
Membuka kembali: klik percakapan untuk beralih ke tab yang sudah menampilkannya; Ctrl+klik (atau Cmd+klik di Mac) menggunakan kembali tab terakhir Anda daripada membuka tab baru.

Mode Prompt:
Klik 📝 pada tombol sakelar di kanan atas ekstensi.
Klik ➕ Tambah Prompt, masukkan judul dan teks Anda, lalu simpan.
Untuk menggunakan prompt: luaskan dan klik ▶ — langsung disuntikkan ke AI aktif, siap dikirim.
Untuk menyematkan prompt: klik 📍 — naik ke bagian atas daftar dan tetap mudah dijangkau.
Pemicu Prompt: Ketik # untuk langsung melihat semua prompt tersimpan Anda, atau lanjutkan mengetik untuk memfilter secara real time. Tekan Spasi pada kecocokan unik untuk pelengkapan otomatis, atau pada kecocokan tepat untuk menyisipkan.

🔒 PRIVASI & KEAMANAN
Dibangun dengan privasi sebagai inti. Hanya meminta akses ke situs-situs AI yang didukung dan URL LLM lokal opsional Anda, dan membaca tab aktif hanya untuk membaca judul percakapan, menyimpannya, atau menyisipkan prompt. Izin "Bookmark" hanya digunakan jika Anda mengaktifkan sinkronisasi mobile. Penyimpanan melalui browser sync: tidak ada server pihak ketiga, tidak ada telemetri, tidak perlu akun.

Dibangun di atas Manifest V3: browser itu sendiri memastikan bahwa tidak ada kode jarak jauh yang dapat dimuat — ini adalah batasan tingkat platform, bukan janji pengembang.
